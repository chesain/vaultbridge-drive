# Clean-room development note

VaultBridge Drive is an independent implementation. No code, file structure, algorithms, comments,
UI text, or implementation details were copied from `RichardX366/Obsidian-Google-Drive`. That
repository was not used as a source. Publicly described failure modes may be treated only as
requirements to avoid.

The implementation is based on the official Obsidian sample plugin and developer API, official
Google OAuth documentation, official Google Drive API v3 documentation, published standards, and
independently designed sync logic. Contributors must preserve this boundary in future changes.
